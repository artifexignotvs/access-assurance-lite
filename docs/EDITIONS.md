# One product, two editions

The free edition is a useful complete local verification workflow. The commercial
edition supplies organizational control and operation around that workflow.
No prices, paying customers or production guarantees are asserted here.

| Capability | Lite candidate | Private commercial candidate |
| --- | --- | --- |
| Local terminal checks, baseline, repeat checks | Included | Existing authenticated terminal workflow |
| Configured cooperating-resource protocol | Included | Evaluated controlled OIDC resource |
| Real HTTP synthetic demo | Included | Existing isolated identity-provider laboratory |
| JSON, CSV, comparison, local evidence | Included | Signed historical evidence and controlled export |
| Team/site authorization and approval roles | No | Implemented within private evaluated scope |
| Durable administrative execution and recovery | No | Implemented within private evaluated scope |
| Finite-model intervention planning | No | Implemented bounded optimizer |
| Encrypted recovery and signing-key rotation | No | Evaluated controlled recovery workflows |
| Managed deployment, support, broader integrations | No | Productization and pilot work remain |
| External audit or production validation | Not established | Not established |

There is no artificial expiry, registration requirement or remote kill switch in
Lite. Limits on resources, response sizes and watch duration bound local resource
use. Team coordination, execution authority and operations are commercial value;
they are not embedded as hidden code in the free package.

The initial Lite implementation is isolated from the inherited private repository.
It does not package private adapters, database code, historical commits or operator
configuration. Its files are independently reviewable and distributed under MIT.
Source availability for Lite does not imply source
availability for the commercial edition.
