# Changelog

## 0.1.0a1 — public alpha

Initial independent Lite edition: original-credential baselines, up to 16
cooperating resources, before/after positive controls, bounded result freshness,
repeated observation, historical JSON evidence, CSV export, comparison and
script-friendly exit codes. Includes the real loopback HTTP demonstration,
synthetic correctness corpus, source tests and reproducible Python archive.

The initial release has no administrative actions, generic web-status inference,
signed evidence, identity-provider adapter, browser-cookie support, packet decoder
or network scanner. The commercial candidate remains a separate private product.
