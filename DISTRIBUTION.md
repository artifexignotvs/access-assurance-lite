# Distribution boundary

Access Assurance Lite is distributed under the MIT license in `LICENSE`.
It may be studied, modified, forked and redistributed under those terms,
including commercial use. Lite is a public alpha with no warranty.

The separately maintained commercial candidate is not included and receives no
license grant from this repository. Its private source, private history,
administrative adapters and operator credentials are excluded.

A Python executable archive contains readable code. It is a convenient package,
not encryption or protection against reverse engineering. Commercial value is
maintained in the separate product, not by claiming public code cannot be copied.

Runtime code uses only the Python standard library. The archive does not bundle
the Python interpreter, third-party wheels, operating-system packages, browsers,
identity providers or containers. Optional source installation uses the external
build backend declared in `pyproject.toml`.
